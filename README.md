# skills
A collection of Claude Code skills I actually use.

## drill-me

Socratic drilling for a technical topic — good for interview prep or just making sure you've actually learned something, not just read about it. Give it a topic, it breaks it into a checklist of sub-concepts, then drills you one at a time with explain-it-back and follow-up questions until each is either demonstrated or flagged as a gap. No multiple choice, no answers handed to you up front. Stateless by design — one topic, one sitting.
